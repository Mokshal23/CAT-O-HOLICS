# CAT-holics // Master Study Portal

A distraction-free, pure dark minimal study portal and structured learning vault curated from the complete repository of **CAT-holics** (authored by IMS mentor *catcracker*). 

Contains **679 curated lessons** covering the entire CAT syllabus across Quantitative Aptitude, Data Interpretation & Logical Reasoning, Verbal Ability & Reading Comprehension, and Exam Strategy.

## Features

- **Pure Dark Minimal UI**: Monochromatic black-and-white theme designed for maximum focus and zero distraction.
- **Original High-Resolution Problem Sheets**: 796 native image sheets preserved with full-screen zoom, pan, and lightbox modal.
- **3,146 Curated Discussions**: Reader doubts and author clarifications highlighting shortcut solutions.
- **Keyboard Shortcuts**:
  - `/` : Instant search across all 679 lessons
  - `[` / `]` or `←` / `→` : Previous / Next lesson
  - `M` : Mark as Read / Unread
  - `B` : Bookmark for revision
  - `Esc` : Close modal / lightbox
- **Offline & Zero Dependencies**: Vanilla HTML5, CSS3, and JavaScript. Zero external library bloat.

## Deployment & Hosting

### Vercel
This repository is configured for one-click static deployment on **Vercel**. Connect this repository to Vercel and it will automatically deploy with zero configuration.

### Local Use
Simply open `index.html` in any browser, or run:
```bash
python server.py
```
Or on Windows, double-click `run_portal.bat`.
